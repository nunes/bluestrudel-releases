# BlueStrudel releases

Instaladores de **BlueStrudel**, live coding musical con Strudel y un copiloto LLM.

Descarga el instalador de Windows más reciente desde la [página de releases](../../releases). La aplicación instalada comprueba al arrancar si hay una versión nueva y, si aceptas, se actualiza sola desde aquí sin volver a abrir el instalador; así que solo hace falta descargarlo una vez.

La versión portable no se actualiza sola: descarga la nueva cuando quieras.

Los ejecutables aún no están firmados, así que Windows SmartScreen avisa la primera vez: **Más información → Ejecutar de todas formas**.

Este repositorio solo contiene los instaladores publicados. El código fuente está en otro lugar.
